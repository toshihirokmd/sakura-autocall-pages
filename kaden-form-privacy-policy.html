架電入力ポップアップ（さくらフォレスト社内用）プライバシーポリシー

最終更新日: 2026 年 10 月 6 日

本書は、さくらフォレスト株式会社（以下「当社」）が提供する Chrome 拡張機能 「架電入力ポップアップ」（以下「本拡張機能」）における情報の取扱いについて定めるものです。 本拡張機能は当社のコンタクトセンターにおける架電（アウトバウンド）業務の記録を効率化するための社内向け業務ツールであり、 当社の従業員（オペレーター）のみが利用します。一般のお客様に向けて配布するものではありません。

1. 取得・処理する情報

本拡張機能は、当社が管理する Google スプレッドシート（架電リスト）上で、以下の情報を取り扱います。

情報の種類取得方法利用目的
架電リストの選択行の内容（顧客 ID・氏名・電話番号など） オペレーターが選択した行を、Google Sheets API でオペレーター本人の権限により読み取り 入力ポップアップにどの顧客の記録かを表示するため、および保存直前に同じ顧客の行であることを確認するため
架電結果の入力内容（話した／メモ／提案結果／自由記述など） オペレーターがポップアップに入力 架電業務の記録・集計
フォーム設定（入力項目の定義） 同じスプレッドシートの「フォーム設定」タブから読み取り ポップアップに表示する入力項目の決定。顧客の個人情報は含みません
操作したオペレーターの Google アカウントのメールアドレス Chrome の identity API で取得 記録の「実施者」欄に記入するため

2. 情報の保存先・送信先

項目保存先・送信先保存期間
架電結果の入力内容・実施者・実施日 オペレーターが開いている当社管理の Google スプレッドシート（同じ行への書き戻し、および同じスプレッドシート内の「記録_タブ名」タブ） 業務記録として当社が保管
Google API のアクセストークン Chrome の identity API が管理（本拡張機能は独自に保存しません） Chrome の管理に従う
フォーム設定・見出しの一時的な控え 拡張機能のメモリ上のみ（ディスクには保存しません） 最大 10 分、またはブラウザの再起動まで

本拡張機能は chrome.storage などのブラウザ内ストレージに顧客情報を保存しません。 読み書きはすべて Google Sheets API（sheets.googleapis.com）を通じ、オペレーター本人の Google アカウントの権限で、 本人が編集権限を持つスプレッドシートに対してのみ行います。

3. 外部送信に関する宣言

本拡張機能は、Google Sheets API（当社が管理する Google スプレッドシート）以外には いかなる外部サーバーにもデータを送信しません。 広告ネットワーク、アクセス解析サービス、第三者のトラッキング SDK は一切組み込まれていません。 取得した情報を販売したり、本来の業務目的以外に利用・転送したりすることはありません。

4. 健康に関する情報の取扱い

当社は健康食品を取り扱っているため、架電結果の自由記述欄に、お客様の体調や商品の体感に関する内容が含まれる場合があります。 これらの情報は架電業務の記録のためにのみ利用し、当社が管理する上記の保存先以外には送信しません。

5. データの削除

  • 本拡張機能はブラウザ内に顧客情報を保存しないため、アンインストール後に端末に顧客情報は残りません。
  • Google スプレッドシートに記録された業務データの削除をご希望の場合は、後述のお問い合わせ先までご連絡ください。

6. セキュリティ対策

  • 本拡張機能は Google スプレッドシート（docs.google.com/spreadsheets）上でのみ動作し、架電リストの形式を持つタブでのみ入力ポップアップを表示します。
  • Google サービスとの通信はすべて TLS（HTTPS）で暗号化されます。
  • OAuth の同意画面は当社の Google Workspace 内部ユーザーに限定しています。
  • 本拡張機能は当社従業員の業務端末でのみ利用されます。

7. 改定

本ポリシーは、関係法令の改正、本拡張機能の機能変更等にあわせて改定する場合があります。 重要な変更が発生した場合は、本ページにて告知します。
